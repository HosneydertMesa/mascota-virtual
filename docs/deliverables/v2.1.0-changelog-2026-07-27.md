# v2.1.0 — Mascota con Vida (2026-07-27)

Upgrade visual y de movimiento de la mascota. NO toca IA, dashboard, quick chat, sonidos, ni settings.

## 🎨 Cambios principales

### Multi-frame walk cycle con bone rotation (skeletal 2D)

El walk cycle ya no es un solo frame estático. Ahora cada pata es **upper-leg + lower-leg** con pivots independientes en hip y knee:

```svg
<g class="back-foot-left" style="transform-origin: 115px 115px; transform: rotate(-15deg)">
  <rect class="upper-leg" ... />     <!-- femur -->
  <g style="transform-origin: 115px 147px; transform: rotate(-60deg)">
    <rect class="lower-leg" ... />   <!-- tibia -->
    <ellipse class="paw" ... />
  </g>
</g>
```

El upper leg pivota en el hip (swing), el lower leg pivota en el knee (bend). Las rotaciones por frame dan el efecto de "fémur + tibia" de un animal real.

**Por frame** (4 frames, cycle a 6 fps):
- **Frame 1 (Contact)**: front-left + back-right planted (diagonal), los otros en aire con knee bent
- **Frame 2 (Down)**: 4 patas plantadas, body squash (cy=118, ry=30)
- **Frame 3 (Pass)**: front-right + back-left planted (la otra diagonal)
- **Frame 4 (Up)**: 4 patas cerca, body stretch (cy=112, ry=34)

### Nuevos states visuales: sit, lay, stretch

5 SVGs nuevos por mascota (10 total) en profile mirando izquierda:
- `catSitSVG` / `dogSitSVG` — sentada/o en patas traseras, body vertical (rx=42, ry=40)
- `catSitBlinkSVG` / `dogSitBlinkSVG` — misma pose con ojo cerrado (anim-blink)
- `catLaySVG` / `dogLaySVG` — acostada/o panza abajo, body horizontal extendido (rx=65, ry=20)
- `catLayBreatheSVG` / `dogLayBreatheSVG` — body un poco más inflado (respiración)
- `catStretchSVG` / `dogStretchSVG` — cuerpo extendido, patas adelante/atrás rotadas 30°

**Total: 18 SVGs nuevos** (4 walk + 4 sit/lay/stretch estáticos por mascota, ×2 = 16... actually 4 walk × 2 + 4 estáticos × 2 = 8 walk + 10 estáticos = 18).

### Look-at-cursor con cabeza rotando (M3)

22 head groups (11 cat + 11 dog) marcados con `class="pet-head"`. El renderer rota la cabeza hacia el cursor del mouse:

- Tracking via `mousemove` global → `mouseX`, `mouseY`
- En cada frame: `atan2(dy, -dx) * 180/π` da el ángulo necesario
- Cap a ±15° para que no parezca exagerado
- Threshold 250px: si el cursor está lejos, vuelve a 0°
- Re-aplicado en el rAF loop para sobrevivir SVG swaps

### Mood affecting motion gradual — lerp en tail wag (M4)

Los valores `tailWagSpeed` y `tailWagAmplitude` ahora son **valores actuales** que lerpean hacia `tailWagSpeedTarget` y `tailWagAmplitudeTarget` (los targets del mood):

- `TAIL_LERP_FACTOR = 0.05` (5% por frame) → ~200-300ms de transición
- `TAIL_LERP_EPSILON = 0.0005` para evitar updates innecesarios
- Cuando el mood cambia (handlePetAction, onPetMoveState), solo se actualizan los TARGETS
- El rAF loop aplica el lerp cada frame

Resultado: la cola **no salta** de velocidad cuando cambia el mood, hace una transición suave.

## 🛠 Detalles técnicos

### Renderer integration (M2)

- `STATE_FRAMES`: map por (petType, state) con arrays de frames
  - walk: 4 frames, sit: 2 frames (blink), lay: 2 frames (breathe), stretch: 1 frame
- `STATE_FRAME_RATE`: ms por frame
  - walk: 167 (6 fps), sit: 2500, lay: 3000, static: Infinity
- `loadMascotSVG(petType, state, withFade)`:
  - `withFade=true` cuando cambia el state (cross-fade 120ms)
  - `withFade=false` para swap directo entre frames del mismo state
- `setVisualState('sitting'|'laying'|'stretching', null, true)` como nuevos states
- `handlePetAction`: action='sit'/'lay'/'stretch' → setVisualState con el state correspondiente

### Pet protocol extension (M1-D)

- `ALLOWED_ACTIONS`: + `sit`, `lay`, `stretch`
- `ALLOWED_INTENTS`: + `rest_sit`, `rest_lay`, `rest_stretch`
- AI prompt actualizado para mencionar las nuevas acciones e intents (cierra el drift que detectó el test `ai-contract`)
