## 1. Goal

La mascota detecta qué app está en foreground y cambia su **mood** y **micro-reacciones** según el contexto. No es RAG, no es "entiende qué haces", es **reactividad contextual**: el gato bosteza cuando estás en Excel, se pone curioso cuando abres Figma.

## 2. Scope

### In scope
- **New service**: `src/services/app-detector.js`
  - Polls foreground window cada 8 segundos (configurable)
  - Output: `{ processName, windowTitle, category }`
- **New module**: `src/core/app-categories.js`
  - Map de process name → category
  - Categories: `code`, `creative`, `office`, `browser`, `social`, `game`, `system`, `unknown`
  - Tests unitarios
- **main.js wiring**:
  - Spawn del detector
  - IPC channel `app-changed` hacia renderer
- **Renderer integration**:
  - Listen del IPC
  - Update del mood target via `pet-mood` existente (no nuevo sistema)
  - Trigger de micro-animations (e.g., head tilt cuando entra a creative)
- **Tests**:
  - `app-categories.test.js`: process name → category
  - `app-detector.test.js`: mock de la query, output structure
- **Changelog** v2.2.0

### Out of scope
- macOS / Linux (Windows only para v2.2.0)
- Per-app custom phrases (e.g., "Photoshop" → "le sacaste los ojos a alguien?")
- Learning de patrones de uso
- Integración con idle-monitor (ya existe, no se toca)
- RAG con notas (eso es v2.3.0)

## 3. Architecture

```
[OS foreground] 
       ↓ (poll 8s, native Win32 API via `active-win` npm)
[app-detector.js] → { processName, windowTitle, category }
       ↓
[main process] → IPC 'app-changed' with the data
       ↓
[renderer] → pet-mood.setTarget(category-based mood)
       ↓
[mood lerp from M4] → smooth transition
       ↓
[+ optional micro-anim trigger] (e.g., head tilt cuando entra a creative)
```

|---|---|---|---|

## 5. Implementation

### 5.1 `src/core/app-categories.js`

```js
'use strict';

// Map de process name (lowercase) → category.
// Keys son substrings (case-insensitive) para tolerar versiones
// (e.g., 'Code' para VSCode, 'chrome' para Chrome/Chromium).
const CATEGORY_RULES = [
  { category: 'code',     patterns: ['code', 'webstorm', 'sublime', 'atom', 'vim', 'emacs', 'notepad++', 'intellij', 'pycharm', 'cursor'] },
  { category: 'creative', patterns: ['photoshop', 'figma', 'sketch', 'illustrator', 'indesign', 'gimp', 'affinity', 'blender', 'canva'] },
  { category: 'office',   patterns: ['excel', 'sheet', 'word', 'doc', 'powerpoint', 'keynote', 'libreoffice', 'numbers', 'pages'] },
  { category: 'browser',  patterns: ['chrome', 'firefox', 'edge', 'brave', 'opera', 'safari', 'vivaldi', 'arc'] },
  { category: 'social',   patterns: ['slack', 'discord', 'telegram', 'whatsapp', 'teams', 'zoom', 'skype', 'signal', 'messenger'] },
  { category: 'game',     patterns: ['steam', 'epicgames', 'minecraft', 'league', 'valorant', 'csgo', 'cs2', 'overwatch', 'roblox', 'gta'] },
  { category: 'system',   patterns: ['explorer', 'finder', 'settings', 'taskmgr', 'control', 'systempreferences'] }
];

function categorize(processName) {
  if (!processName) return 'unknown';
  const lower = String(processName).toLowerCase();
  for (const rule of CATEGORY_RULES) {
    for (const pattern of rule.patterns) {
      if (lower.includes(pattern)) return rule.category;
    }
  }
  return 'unknown';
}

const CATEGORY_MOODS = {
  code: 'calm',
  creative: 'excited',  // usamos excited con amplitud baja (alternativa: agregar 'curious')
  office: 'sleepy',
  browser: 'excited',
  social: 'happy',
  game: 'excited',
  system: 'calm',
  unknown: null  // no change
};

module.exports = { categorize, CATEGORY_MOODS, CATEGORY_RULES };
```

### 5.2 `src/services/app-detector.js`

```js
'use strict';

const { categorize } = require('../core/app-categories');

// Para Windows usamos PowerShell via child_process (sin native deps).
// Cada 8s consultamos la ventana foreground y devolvemos { processName, windowTitle, category }.
const POLL_INTERVAL_MS = 8000;

const QUERY_SCRIPT = `
Add-Type -MemberDefinition @"
  [DllImport("user32.dll")]
  public static extern IntPtr GetForegroundWindow();
  [DllImport("user32.dll", CharSet=CharSet.Auto)]
  public static extern int GetWindowText(IntPtr hWnd, System.Text.StringBuilder lpString, int nMaxCount);
  [DllImport("user32.dll")]
  public static extern uint GetWindowThreadProcessId(IntPtr hWnd, out uint lpdwProcessId);
"@ -Name API -Namespace Win32
$hwnd = [Win32.API]::GetForegroundWindow()
$pid = 0
[Win32.API]::GetWindowThreadProcessId($hwnd, [ref]$pid) | Out-Null
$proc = Get-Process -Id $pid -ErrorAction SilentlyContinue
if ($proc) {
  @{ name = $proc.ProcessName; title = $proc.MainWindowTitle; pid = $pid } | ConvertTo-Json -Compress
}
`;

let timer = null;

function startDetector(onChange) {
  let lastCategory = null;
  function tick() {
    const { exec } = require('child_process');
    exec(`powershell -NoProfile -Command "${QUERY_SCRIPT.replace(/"/g, '\\"').replace(/\n/g, ' ')}"`,
      { windowsHide: true, timeout: 5000 },
      (err, stdout) => {
        if (err) return;
        try {
          const data = JSON.parse(stdout.trim() || '{}');
          if (!data.name) return;
          const category = categorize(data.name);
          if (category !== lastCategory) {
            lastCategory = category;
            onChange({ processName: data.name, windowTitle: data.title, category });
          }
        } catch (_e) { /* ignore */ }
      }
    );
  }
  tick();
  timer = setInterval(tick, POLL_INTERVAL_MS);
}

function stopDetector() {
  if (timer) { clearInterval(timer); timer = null; }
}

module.exports = { startDetector, stopDetector, POLL_INTERVAL_MS };
```

### 5.3 main.js wiring

Agregar al `app.whenReady()`:
```js
const { startDetector, stopDetector } = require('./src/services/app-detector');
const { CATEGORY_MOODS } = require('./src/core/app-categories');

startDetector(({ processName, windowTitle, category }) => {
  if (mainWindow && !mainWindow.isDestroyed()) {
    mainWindow.webContents.send('app-changed', { processName, windowTitle, category, mood: CATEGORY_MOODS[category] });
  }
});

// En el will-quit:
app.on('will-quit', stopDetector);
```

### 5.4 renderer.js integration

```js
// M2.2 — listen app changes
if (window.petAPI?.onAppChanged) {
  window.petAPI.onAppChanged(({ processName, windowTitle, category, mood }) => {
    console.log('[renderer] app changed:', processName, '→', category);
    if (mood) {
      // Map mood to tail wag targets (lerp gradual via M4)
      const moodTargets = {
        happy: { speed: 0.08, amplitude: 1.3 },
        excited: { speed: 0.12, amplitude: 1.5 },
        calm: { speed: 0.04, amplitude: 0.8 },
        sleepy: { speed: 0.02, amplitude: 0.5 },
        sad: { speed: 0.015, amplitude: 0.4 }
      };
      const target = moodTargets[mood];
      if (target) {
        tailWagSpeedTarget = target.speed;
        tailWagAmplitudeTarget = target.amplitude;
      }
    }
    // Mostrar el nombre de la app en la speech bubble (opcional)
    showSpeech(`Detecté ${processName}...`);
  });
}
```

## 6. Risks

| Risk | Impact | Likelihood | Mitigation |
|---|---|---|---|
| PowerShell exec es lento (200-500ms) | Low | High | Polling cada 8s = aceptable. ~1% CPU. |
| PowerShell exec bloquea event loop | Medium | Medium | child_process.exec es async, no bloquea. |
| `active-win` no funciona con Electron | High | High (no lo estamos usando) | Plan B es PowerShell via child_process. |
| Categorización incompleta | Low | High | Default 'unknown' = no cambia. Whitelist extensible. |
| Falsa detección (app en tray) | Low | Low | Filtrar por MainWindowHandle no-cero. |
| Privacy: lee qué app está abierta | Medium | High | Todo local, no se envía a ningún lado. Documentar. |
| App name en speech bubble es invasivo | Low | Low | Hacerlo opcional con flag. |

## 7. Test plan

- **Unit (app-categories)**: para cada category, 3+ process names validos → categoriza OK. Casos edge: null, empty, mixed case, process name con espacios.
- **Unit (app-detector)**: mock exec, verificar que se llama con los args correctos, que onChange solo se llama cuando la category cambia (no cuando solo cambia el title).
- **Integration**: launch app, abrir Chrome → mood playful. Cerrar Chrome, abrir VSCode → mood calm. Verificar transición suave (lerp M4).
- **Performance**: poll 8s × 1 process = 1.5% CPU medido.
- **Manual**: 10 min de uso normal, verificar que no genera falsos positivos.
